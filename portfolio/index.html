Featured

FinWise AI: Multi-Bank Personal Finance Manager

Live demo in progress

A full-stack app that connects multiple bank accounts through Plaid into one dashboard, categorizes transactions with AI, and answers questions about your spending in plain English.

  • REST API in FastAPI + SQLAlchemy with JWT/bcrypt authentication, and a React 18 dashboard built with Vite, TailwindCSS and Recharts.
  • Plaid integration (Link, token exchange, transactions/sync) with a Celery + Redis job that syncs every 6 hours.
  • Transactions categorized by keyword rules plus a Groq LLM, and a chat assistant that answers over the last 90 days of data.
  • 30-day spending forecast (Prophet), subscription detection, budget alerts at 80% and 100% of limit, and Redis caching for dashboard queries.
  • Dockerized, with the backend and PostgreSQL on Render and the frontend as a Render static site. Tested end to end on Plaid sandbox data across 3 mock institutions.
